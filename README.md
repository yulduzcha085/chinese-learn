# Xitoy Tilini O‘rganish Sayti

Bu loyiha xitoy tilini o‘rganmoqchi bo‘lganlar uchun mo‘ljallangan veb-ilova bo‘lib, foydalanuvchilarga lug‘at, talaffuz, va grammatika bo‘yicha interaktiv darslar va testlar orqali yordam beradi.

## 🧠 Xususiyatlar

- 📚 Xitoy tilidagi asosiy so‘zlar va iboralarni o‘rganish
- 🔊 Talaffuzni eshitish imkoniyati (audio fayllar bilan)
- 📝 Interaktiv testlar va mashqlar
- 📈 O‘quv yutuqlarini kuzatish
- 📱 Mobil va desktop qurilmalarda ishlashga mos dizayn

## 💻 Texnologiyalar

- Frontend: HTML, CSS, JavaScript
