# Xitoy Tili O'rganish Platformasi

Bu platforma xitoy tilini o'rganishni istagan o'zbek foydalanuvchilari uchun yaratilgan. Platforma quyidagi imkoniyatlarni taqdim etadi:

- Xitoycha-O'zbekcha lug'at
- Interaktiv darslar
- O'rganish materiallari
- Progress kuzatish tizimi

## O'rnatish

1. Loyihani clone qiling:
```bash
git clone [repository-url]
```

2. Kerakli paketlarni o'rnating:
```bash
npm install
```

3. Loyihani ishga tushiring:
```bash
npm start
```

## Ishlatish

Loyiha http://localhost:3000 manzilida ishga tushadi.

### Asosiy bo'limlar:

1. **Bosh sahifa** - Platformaga umumiy ma'lumot
2. **Lug'at** - Xitoycha so'zlarni qidirish va o'rganish
3. **O'rganish** - Interaktiv darslar va mashqlar
